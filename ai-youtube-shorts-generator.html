How it works

From long-form video to ready-to-post shorts

The workflow combines captioning, highlight detection, deduplication, and crop logic into a single path that outputs top-scoring clips.

1

Download

Pull the source video from YouTube or a local file path and prepare it for analysis.

2

Transcribe

Generate a timestamped transcript via Whisper so the system can identify the key moments.

3

Rank

Use an LLM to score hook strength, opinion spikes, emotional peaks, and practical value.

4

Deduplicate

Collapse overlapping highlights so you keep the strongest clip instead of near-duplicates.

5

Crop

Auto-generate 9:16 vertical shorts with face tracking and motion-aware framing.

Quick start

Run it locally in a few commands

git clone https://github.com/SamurAIGPT/AI-Youtube-Shorts-Generator.git cd AI-Youtube-Shorts-Generator python3.10 -m venv venv source venv/bin/activate pip install -r requirements.txt python main.py "https://www.youtube.com/watch?v=VIDEO_ID" \ --mode api \ --num-clips 5 \ --aspect-ratio 9:16 \ --output-json result.json

What you get

  • Top virality-ranked clips
  • JSON output for automation
  • CLI + Python library
  • Local or API execution mode
  • Custom aspect ratios
